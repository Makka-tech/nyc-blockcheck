# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity or expression, experience level, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behavior

Use welcoming language, respect differing viewpoints, accept constructive feedback, focus on what is best for the community, and show empathy.

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, doxxing, and sustained disruption are not tolerated.

## Enforcement

Report concerns privately to the maintainers through the repository’s security contact. Maintainers may remove, edit, reject, or otherwise respond to contributions that do not align with this Code of Conduct.

This policy is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
