# Security policy

Please do not disclose vulnerabilities in public issues. Report them privately to the repository maintainers using GitHub’s private vulnerability reporting feature, or contact the organization owner directly if that feature is unavailable.

Include a clear reproduction, impact, affected version or commit, and any suggested mitigation. We will acknowledge the report, investigate it, and coordinate a fix before public disclosure when appropriate.

Never include API tokens, personal data, or tenant-identifying information in an issue, pull request, test fixture, or report.
